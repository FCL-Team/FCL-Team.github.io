# 上传键位布局

FCL 允许你制作自己的触屏键位布局，并与所有人分享。本指南介绍如何提交布局，以及布局在启动器中上架前审核组会检查哪些内容。

:::caution 上传之前
请勿上传仅供个人使用的布局。请只提交为其他玩家设计的布局。
:::

## 上传步骤

### 1. 打开键位页面

打开 FCL，点击左侧边栏的键位图标，然后选择要上传的布局。点击**上传布局**，而不是**分享布局**。

![选择布局并点击“上传布局”](/img/docs/upload-controller/upload.png)

### 2. 点击分享

在下一个界面点击**分享**。前提是你已获准加入 FCL 键位审核群。

![点击分享](/img/docs/upload-controller/share_pri.png)

### 3. 填写布局信息

在对话框中填写布局信息，并选择布局语言和它适用的设备类型。挑选一个图标，以及一张用红色标出按键的截图。

![编辑布局信息](/img/docs/upload-controller/info.png)

:::note
如果找不到图片路径，可以使用文件管理器（例如 MT 管理器）把图片移动到容易找到的位置。
:::

### 4. 分享生成的压缩包

再次点击**分享**。FCL 会生成一个以八位字符 ID 命名的压缩包。把该压缩包发送到审核群，等待审核人员处理。

![生成的压缩包](/img/docs/upload-controller/share_sec.png)

![在审核群中分享](/img/docs/upload-controller/community.png)

## 审核规则

### 功能与设计

1. **功能完整**——布局必须提供核心按键。
2. **原创性**——未经许可，不得照搬其他布局的风格、排布、文字或特殊功能。如果借鉴了他人创意，请取得**原作者授权**，在描述中注明原作者，并将授权证明发送至审核群。
3. **禁止商业推广**——不得进行任何形式的广告宣传。

### 文件要求

1. **命名**——为八位字符的压缩包起一个合适的名称，避免使用违禁词（例如“作弊”“无敌”“独家”“最强”）。
2. **分类清晰**——完整填写分类和语言字段。
3. **截图**——使用展示布局本身的截图，而不是与布局无关的游戏画面。
4. **图标**——图标应尽量接近 1:1 的宽高比；使用个人头像也可以。
5. **推荐品质**——美观且原创的风格、合理的按键位置、丰富多样的按键功能，以及至少两个控件组。

### 常见问题

- **图片错误或毫无意义**——图标应接近 1:1 且易于辨认；截图应展示布局，而不是游戏画面。
- **抄袭**——检查是否存在抄袭内容，注明原作者并提供授权。
- **文件类型错误**——请上传八位字符的压缩包；不要上传原始的 `.json` 文件、重命名压缩包或重新压缩 JSON。
- **仅供个人使用或质量低下**——不要上传只适合自己习惯或明显未完成的布局。
- **风格不合格**——避免奇怪的颜色、极端的亮度或透明度，以及未对齐的按键。
- **文件被撤回**——审核结束后，通过和未通过的文件都会从群中撤回，以保持群内秩序。请留意审核通知。
- **暂无回复**——审核由人工完成。通过审核并不意味着布局会立即在启动器中上架，请耐心等待。

### 群规

审核群管理严格：

- 加入后一天内未上传布局的成员会被移出。
- 不允许使用多个账号，也不允许闲聊。
- 任何未经授权使用其他布局风格的内容，必须先改造成原创内容才能上传。
