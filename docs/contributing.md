# 贡献指南

FCL 由志愿者共同打造，参与方式有很多——即使你不写代码也能帮上忙。

## 反馈问题

1. 先搜索[已有的 issue](https://github.com/FCL-Team/FoldCraftLauncher/issues)。
2. 如果这是一个新问题，请提交 issue，并附上：
   - 你的 FCL 版本、设备型号和 Android 版本；
   - 清晰的问题复现步骤；
   - 启动器日志（这通常是查找原因最快的方式）。
3. 请保持耐心——参与 FCL 的每个人都是志愿者。

## 参与翻译

翻译在 [Weblate](https://hosted.weblate.org/projects/foldcraftlauncher/) 上管理。无需任何工具或本地配置：注册账号，选择你的语言，就可以在浏览器中开始翻译。

## 完善文档

文档位于 [FCL-Docs](https://github.com/FCL-Team/FCL-Docs) 仓库。如果你发现错误或想添加指南，可以在那里提交 pull request 或 issue。你现在阅读的这些页面正是由该仓库的内容构建的，并托管在[网站仓库](https://github.com/FCL-Team/FCL-Team.github.io)中。

## 分享键位布局

你可以制作自定义键位布局并提交审核。具体流程和审核规则请参阅[上传键位布局](/docs/controller-upload)。

## 贡献代码

1. Fork [FoldCraftLauncher 仓库](https://github.com/FCL-Team/FoldCraftLauncher)。
2. 为你的改动创建一个分支。
3. 保持改动聚焦，并遵循现有的代码风格。
4. 提交 pull request，说明这次改动**做了什么**以及**为什么**。

对于较大的改动或新功能，请先提交 issue 或发起讨论，这样维护者可以在你投入大量时间之前分享他们的想法。
