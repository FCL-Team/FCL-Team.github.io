# 简介

**Fold Craft Launcher**（FCL）是一款面向 Android 的开源 Minecraft: Java Edition 启动器。它基于 [HMCL](https://github.com/HMCL-dev/HMCL) 的启动器内核与 [Amethyst-Android](https://github.com/AngelAuraMC/Amethyst-Android) 游戏后端，因此手机或平板可以运行真正的 Java 版——而不是仿制版。

FCL 是以 [GPL-3.0 许可证](https://www.gnu.org/licenses/gpl-3.0.html)发布的自由软件，由 [FCL-Team](https://github.com/FCL-Team) 与社区共同开发。

## FCL 能做什么

- 运行**每一个 Minecraft 版本**，从 Alpha、Beta 快照到最新正式版
- 搭配 **Forge、NeoForge、Fabric、Quilt、LiteLoader、OptiFine 和 Cleanroom** 游玩
- 使用**内置的 Java 8、17、21 和 25 运行时**，也可以导入自己的运行时
- 在启动器内管理**模组、整合包、资源包、光影和世界**
- 使用 VirGL、Zink 或 MobileGlues 渲染器运行**光影**
- 创建**自定义键位布局**，使用虚拟鼠标，并导入 ZalithLauncher 2 布局
- 自定义**背景和配色方案**，并通过渲染器或驱动插件扩展启动器

## 环境要求

- Android 8.0（API 26）或更高版本
- 建议使用 64 位 ARM 设备，以获得最佳体验
- 为 APK 和游戏文件预留足够的可用存储空间

## 快速开始

1. 为你的设备[下载最新版本](/download)。
2. 安装 APK 并打开 FCL。
3. [添加账号](/docs/account)——Microsoft、离线，或第三方认证服务器。
4. 下载一个 Minecraft 版本，然后点击开始游戏。
