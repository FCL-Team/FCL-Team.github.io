# 账号设置

FCL 支持三种账号：

- **Microsoft 账号**——拥有 Minecraft: Java Edition 的玩家使用的官方登录方式
- **离线账号**——本地用户名，适合单人游戏和局域网世界
- **第三方认证服务器**——皮肤站及其他兼容 Yggdrasil 的服务

你可以添加多个账号，并在账号菜单中切换。

## Microsoft 账号（官方登录）

:::warning
使用 Microsoft 账号登录需要该账号已购买并激活 Minecraft: Java Edition。否则登录将无法完成。
:::

1. 打开启动器右上角的账号菜单。
2. 选择**官方登录**，然后点击**登录**。
3. 界面会显示一个设备代码，并复制到剪贴板。在浏览器中打开登录页面，粘贴代码并点击**下一步**。
4. 输入你的 Microsoft 账号密码，等待确认信息。
5. 返回 FCL——此时已登录。

## 离线账号

1. 在账号菜单中，选择**离线登录**（位于 Microsoft 登录按钮下方）。
2. 输入 3 到 16 个字符的用户名。
3. 点击**登录**。

:::note
不支持空格——请改用下划线。较新的版本只接受字母、数字和下划线。
:::

## 第三方认证服务器

1. 在账号菜单中，选择**添加认证服务器**。
2. 输入受支持的 Yggdrasil 认证服务器地址，例如：
   - LittleSkin：`https://littleskin.cn/api/yggdrasil`
   - Naituskin：`https://naituskin.cn/api/yggdrasil`
3. 访问该服务器的网站，创建角色并设置密码。
4. 返回 FCL，选择该认证服务器，输入角色名和密码，然后点击**登录**。

:::tip
只添加你信任的认证服务器。第三方服务器并非由 FCL-Team 运营。
:::
