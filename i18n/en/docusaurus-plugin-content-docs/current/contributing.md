# Contributing

FCL is built by volunteers, and there are many ways to help — even if you do not write code.

## Report a bug

1. Search the [existing issues](https://github.com/FCL-Team/FoldCraftLauncher/issues) first.
2. If the problem is new, open an issue with:
   - your FCL version, device model and Android version,
   - clear steps to reproduce the problem,
   - the launcher log attached (it is usually the fastest way to find the cause).
3. Please be patient — everyone working on FCL is a volunteer.

## Translate

Translations are managed on [Weblate](https://hosted.weblate.org/projects/foldcraftlauncher/). No tools or local setup are required: create an account, pick your language and start translating in the browser.

## Improve the documentation

The documentation lives in the [FCL-Docs](https://github.com/FCL-Team/FCL-Docs) repository. If you spot a mistake or want to add a guide, open a pull request or an issue there. The pages you are reading now are built from that content and live in the [website repository](https://github.com/FCL-Team/FCL-Team.github.io).

## Share controller layouts

You can create custom touch layouts and submit them for review. See [Upload a controller layout](/docs/controller-upload) for the process and the review rules.

## Contribute code

1. Fork the [FoldCraftLauncher repository](https://github.com/FCL-Team/FoldCraftLauncher).
2. Create a branch for your change.
3. Keep the change focused and follow the existing code style.
4. Open a pull request describing **what** the change does and **why**.

For large changes or new features, please open an issue or start a discussion first, so the maintainers can share their thoughts before you invest a lot of time.
