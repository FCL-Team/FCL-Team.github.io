# Introduction

**Fold Craft Launcher** (FCL) is an open-source Minecraft: Java Edition launcher for Android. It is built on the launcher core of [HMCL](https://github.com/HMCL-dev/HMCL) and the [Amethyst-Android](https://github.com/AngelAuraMC/Amethyst-Android) game backend, so a phone or tablet can run the real Java Edition — not a clone.

FCL is free software released under the [GPL-3.0 license](https://www.gnu.org/licenses/gpl-3.0.html), developed by [FCL-Team](https://github.com/FCL-Team) with help from the community.

## What you can do with FCL

- Run **every Minecraft version**, from Alpha and Beta snapshots to the newest release
- Play with **Forge, NeoForge, Fabric, Quilt, LiteLoader, OptiFine and Cleanroom**
- Use the **bundled Java 8, 17, 21 and 25 runtimes**, or import your own
- Manage **mods, modpacks, resource packs, shaders and worlds** from inside the launcher
- Run **shaders** with the VirGL, Zink or MobileGlues renderers
- Create **custom controller layouts**, use a virtual mouse and import ZalithLauncher 2 layouts
- Customize **backgrounds and color schemes**, and extend the launcher with renderer or driver plugins

## Requirements

- Android 8.0 (API 26) or newer
- A 64-bit ARM device is recommended for the best experience
- Enough free storage for the APK plus your game files

## Getting started

1. [Download the latest release](/download) for your device.
2. Install the APK and open FCL.
3. [Add an account](/docs/account) — Microsoft, offline, or a third-party authentication server.
4. Download a Minecraft version and press play.
